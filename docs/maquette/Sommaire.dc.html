Pour Claude Code · structure
Une planche = un écran. Les liens entre planches donnent la navigation. Chaque espace de jeu (Dames, Ludo, Raisonnement) partage le même profil et a son propre niveau. Barre du bas : Accueil · Jouer (dernier espace utilisé) · Ligues · Cartes · Profil. Cachée pendant une partie.
Pour Claude Code · design
Fond #0F1230, surfaces #20265A, bordures #3D4590, texte #F4EEDF, texte secondaire #A9AECF. Or #F2B705 seulement pour l'action et « à toi ». Damier #F1E2BF / #A8703F. Titres Unbounded, texte DM Sans. Tissus en motifs CSS (ndop, toghu, kaba, obom), jamais en images.
Pour Claude Code · règles
Toutes les règles chiffrées sont dans les planches « Réf » en bas du canevas : données et cauris, ligues publiques (caution, forfaits, exclusion, calendrier), matrice des droits et des états, tailles d'écran, et le moteur de jeu (IA) avec ses échelons. Le serveur fait foi pour chaque coup, chaque mise et chaque lancer de dé.
